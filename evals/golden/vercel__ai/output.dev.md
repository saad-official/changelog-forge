## vercel/ai ai@7.0.126...ai@7.0.127

This release adds configurability to the tool search API, introduces new error types and model support, and includes several documentation updates. It also contains fixes for stream cancellation, chat state batching, and JSON comparison logic.

### Features

- Introduces `toolSearch({ maxResults })` to allow callers to set the maximum number of tools returned; default remains five. ([#21897](https://github.com/vercel/ai/pull/21897))
- Adds an optional `search` callback to `toolSearch()` to select and rank eligible deferred tools. ([#21903](https://github.com/vercel/ai/pull/21903))
- Exports `AuthorizationServerMismatchError` with errorCode 'authorization_server_mismatch' for OAuth pin mismatches. ([#20560](https://github.com/vercel/ai/pull/20560))
- Introduces Azure MAI-Voice-2.1, MAI-Voice-2.1-Flash, and MAI-Transcribe-2-Streaming models to the SDK. ([#21910](https://github.com/vercel/ai/pull/21910))
- Added `requestMetadata: Record&lt;string,string>` to `providerOptions.amazonBedrock` for Converse and ConverseStream APIs. ([#20415](https://github.com/vercel/ai/pull/20415))

### Fixes

- Propagates consumer cancellation to merged streams in `createUIMessageStream` and cancels pending pulls. ([#21728](https://github.com/vercel/ai/pull/21728))
- Updates `useChat` to batch state updates and avoid navigation starvation during streaming responses. ([#21874](https://github.com/vercel/ai/pull/21874))
- Updated deep JSON comparison in `validate-tool-approvals.ts` to treat objects and arrays from different realms as equivalent. ([#21810](https://github.com/vercel/ai/pull/21810))

### Docs
