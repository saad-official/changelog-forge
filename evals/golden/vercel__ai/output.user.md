## What's new in vercel/ai ai@7.0.127

This release gives you more control over tool searches and adds support for new Azure voice and transcription models. It also fixes streaming behavior so UI updates and navigation work more smoothly.

### Features

- Adds support for new Azure MAI-Voice and MAI-Transcribe models. ([#21910](https://github.com/vercel/ai/pull/21910))
- You can now add request metadata to Bedrock Converse requests for cost attribution. ([#20415](https://github.com/vercel/ai/pull/20415))
- Adds a configurable maximum number of tools returned by tool search. ([#21897](https://github.com/vercel/ai/pull/21897))
- Adds a callback to tool search for custom ranking of deferred tools. ([#21903](https://github.com/vercel/ai/pull/21903))
- Adds a specific error for OAuth authorization server mismatches. ([#20560](https://github.com/vercel/ai/pull/20560))

### Fixes

- Prevents streamed chat updates from blocking navigation in Next.js App Router. ([#21874](https://github.com/vercel/ai/pull/21874))
- Ensures UI message stream cancellation stops all merged sources. ([#21728](https://github.com/vercel/ai/pull/21728))
- Tool approvals from other JavaScript realms are now accepted. ([#21810](https://github.com/vercel/ai/pull/21810))
