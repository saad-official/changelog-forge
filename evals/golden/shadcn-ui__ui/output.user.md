## What's new in shadcn-ui/ui shadcn@4.21.1

This release adds support for OIDC authentication and introduces a new registry API package. It also expands the list of available UI registries and improves visual and accessibility details.

### Features

- Added OIDC support to the application. ([afda008](https://github.com/shadcn-ui/ui/commit/afda0085e042a06ceb4d6e97ebd4f5025d389076))
- A new package `@shadcn/registry` provides the registry API for external use. ([#12087](https://github.com/shadcn-ui/ui/pull/12087))
- You can now discover and use new community registries added to the directory. ([#11925](https://github.com/shadcn-ui/ui/pull/11925), [#11861](https://github.com/shadcn-ui/ui/pull/11861), [#11915](https://github.com/shadcn-ui/ui/pull/11915), [#11924](https://github.com/shadcn-ui/ui/pull/11924), [#11976](https://github.com/shadcn-ui/ui/pull/11976), [#12037](https://github.com/shadcn-ui/ui/pull/12037), [#12052](https://github.com/shadcn-ui/ui/pull/12052), [#12059](https://github.com/shadcn-ui/ui/pull/12059))
- The Corsair UI copy-and-own component registry is now available. ([#12033](https://github.com/shadcn-ui/ui/pull/12033))
- The registry directory is now ranked by health and catalog size. ([#12058](https://github.com/shadcn-ui/ui/pull/12058))
- You can now use the new Quiz UI registry for building unstyled quiz funnels. ([#11753](https://github.com/shadcn-ui/ui/pull/11753))
