## What's new in vitest-dev/vitest v5.0.3

This release improves the stability of test runs and fixes several issues that could cause unexpected behavior in the browser and UI. It also tightens caching and cleanup to keep your environment tidy.

### Fixes

- Tests marked to fail no longer trigger retries. ([#11219](https://github.com/vitest-dev/vitest/pull/11219))
- Cached modules now update when imports change. ([#11381](https://github.com/vitest-dev/vitest/pull/11381))
- Cache key generators are now scoped per project, preventing cross‑project cache contamination. ([#11301](https://github.com/vitest-dev/vitest/pull/11301))
- Delays browser server listening until tests start to avoid optimizer errors. ([#11366](https://github.com/vitest-dev/vitest/pull/11366))
- Suppresses interceptor warning in browser mode for security. ([#11377](https://github.com/vitest-dev/vitest/pull/11377))
- Preserves browser environment config for consumer client environments. ([#11378](https://github.com/vitest-dev/vitest/pull/11378))
- Adds Blob support for jsdom 30.1. ([#11379](https://github.com/vitest-dev/vitest/pull/11379))
- Removes root temporary directory on Vitest close to avoid leaks. ([#11248](https://github.com/vitest-dev/vitest/pull/11248))
- Fixes split-pane handle overlapping iframe in UI. ([#11221](https://github.com/vitest-dev/vitest/pull/11221))
- Page crashes during cancellation are ignored, preventing flaky CI failures. ([#11386](https://github.com/vitest-dev/vitest/pull/11386))
- Pool IDs are now correctly preserved across group orders, avoiding duplicate IDs. ([#11392](https://github.com/vitest-dev/vitest/pull/11392))
- `toMatchScreenshot` now uses the correct reference for retried tests. ([#11393](https://github.com/vitest-dev/vitest/pull/11393))
- VM runner now applies dependency optimizer config, preventing failures when index.html imports unbundlable deps. ([#11360](https://github.com/vitest-dev/vitest/pull/11360))
- Asymmetric matchers now correctly use the current equality testers when created via `expect.extend`. ([#11401](https://github.com/vitest-dev/vitest/pull/11401))
- Fixed script reuse across different Vite environments to prevent mock and module instance issues. ([#11395](https://github.com/vitest-dev/vitest/pull/11395))
- Corrects mock path resolution boundaries in browser mocks. ([#11362](https://github.com/vitest-dev/vitest/pull/11362))
- Ensures each repeat run has isolated result status, preventing false passes. ([#11218](https://github.com/vitest-dev/vitest/pull/11218))
