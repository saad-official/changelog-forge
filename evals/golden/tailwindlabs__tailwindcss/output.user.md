## What's new in tailwindlabs/tailwindcss v4.3.0

This release improves the reliability of plugins and imports, and adds a set of new utilities for styling scrollbars, scaling elements, and tab size. It also refines variant handling and fixes several edge‑case issues with arbitrary values and TypeScript imports.

### Features

- Variants using &:has are now converted to has-[] syntax. ([#19991](https://github.com/tailwindlabs/tailwindcss/pull/19991))
- Adds `scrollbar-gutter-*` utilities to control scrollbar gutter behavior. ([#20018](https://github.com/tailwindlabs/tailwindcss/pull/20018))
- Adds `zoom-*` utilities for scaling elements with percentage or arbitrary values. ([#20020](https://github.com/tailwindlabs/tailwindcss/pull/20020))
- Adds `tab-*` utilities to set the tab-size property. ([#20022](https://github.com/tailwindlabs/tailwindcss/pull/20022))
- New utilities for scrollbar-width and scrollbar-color are available. ([#19981](https://github.com/tailwindlabs/tailwindcss/pull/19981))
- Multiple `@utility` definitions with same name but different value types now work. ([#19777](https://github.com/tailwindlabs/tailwindcss/pull/19777))
- You can now use --default(…) inside --value(…) or --modifier(…) for fallback values. ([#19989](https://github.com/tailwindlabs/tailwindcss/pull/19989))
- You can now write compound and stacked `@variant` rules using comma and colon syntax. ([#19996](https://github.com/tailwindlabs/tailwindcss/pull/19996))

### Fixes

- Resolves JS plugin imports correctly, avoiding CSS misresolution. ([#19949](https://github.com/tailwindlabs/tailwindcss/pull/19949))
- Relative imports now resolve to the correct file. ([#19965](https://github.com/tailwindlabs/tailwindcss/pull/19965))
- Plugin now resolves tailwindcss correctly even without a from option. ([#19980](https://github.com/tailwindlabs/tailwindcss/pull/19980))
- Whitespace in arbitrary values is preserved correctly. ([#19986](https://github.com/tailwindlabs/tailwindcss/pull/19986))
- Unit normalization no longer applied to arbitrary values. ([#19988](https://github.com/tailwindlabs/tailwindcss/pull/19988))
- Upgrade tool no longer changes CSS properties inside style attributes. ([#19918](https://github.com/tailwindlabs/tailwindcss/pull/19918))
- TypeScript error TS2742 no longer occurs when importing Config type. ([#19707](https://github.com/tailwindlabs/tailwindcss/pull/19707))
- CSS for start and end utilities is no longer generated when no value is provided. ([#20003](https://github.com/tailwindlabs/tailwindcss/pull/20003))
- Functional `@utility` definitions now require --value(…) to avoid accidental empty utilities. ([#20005](https://github.com/tailwindlabs/tailwindcss/pull/20005))
- Math operators in arbitrary values are now surrounded by whitespace for valid CSS. ([#20011](https://github.com/tailwindlabs/tailwindcss/pull/20011))
- `@variant` directives are now processed by the Vite plugin. ([#19966](https://github.com/tailwindlabs/tailwindcss/pull/19966))
