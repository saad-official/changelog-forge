## What's new in drizzle-team/drizzle-orm 0.45.0

This release adds new capabilities for building queries and improves reliability when working with PostgreSQL. You’ll also see several fixes that make transactions and schema handling work as expected.

### Features

- Users can now include subqueries in SELECT fields with proper typing. ([#1674](https://github.com/drizzle-team/drizzle-orm/pull/1674))
- Drizzle Kit now offers an extended API for developers. ([#4999](https://github.com/drizzle-team/drizzle-orm/pull/4999))

### Fixes

- Transactions now work correctly with pg-native connection pools. ([#1708](https://github.com/drizzle-team/drizzle-orm/pull/1708))
- Drizzle Kit now correctly introspects Postgres 18 schemas without unnecessary DROP statements. ([#5034](https://github.com/drizzle-team/drizzle-orm/pull/5034))
- Corrected a typo in the algorithm name in serializers. ([#1676](https://github.com/drizzle-team/drizzle-orm/pull/1676))
