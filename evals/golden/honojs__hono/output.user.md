## What's new in honojs/hono v4.13.13

This release adds a new way to publish the Netlify adapter and improves several middleware behaviors. It also introduces a breaking change to how mounting works.

### Breaking changes

- Mount middleware introduced, replacing app.mount. ([#5221](https://github.com/honojs/hono/pull/5221))
  - Migration: Replace app.mount calls with mount(ittyRouter.handle) and remove app.mount import.

### Features

- Netlify adapter can now be published to JSR. ([#5468](https://github.com/honojs/hono/pull/5468))

### Fixes

- some() middleware now returns a Response correctly when short‑circuiting. ([#5391](https://github.com/honojs/hono/pull/5391))
- ETag middleware now correctly retains headers with mixed‑case names. ([#5475](https://github.com/honojs/hono/pull/5475))
- Bundled declarations no longer expose internal types or self‑referencing JSX.IntrinsicElements. ([#5485](https://github.com/honojs/hono/pull/5485))
- Numeric gridGap, gridRowGap, gridColumnGap now have px units in JSX. ([#5487](https://github.com/honojs/hono/pull/5487))
- JSX function components can now return JSXNode directly or via promise. ([#5476](https://github.com/honojs/hono/pull/5476))
